## Why the memory chart shows ranges, not per-task bars

The outline asked for per-task GPU memory at 16,384 environments. Those per-task values (e.g. Isaac-Velocity-Flat-G1-v0)
exist only on a slide in the screenshot set (`context/sources/05a-screenshots-batch1.md`, kept local, #20), and that slide belongs to
"Deck B", which carries an "NVIDIA CONFIDENTIAL. DO NOT DISTRIBUTE" footer. The public SIGGRAPH 2026 talk transcript states
only the ranges ("somewhere between 2 to 3x … steps per second", "3 to 4x less memory usage", "previously you could do
4,000 environments. Now … 16,000 on the same GPU", tiled rendering "2 to 3x faster" and "5 to 10x less memory"), and the
Newton repo/docs publish no PhysX comparison. So the chart plots the stated ranges only. Do not add per-task numbers
unless they appear in a public source.

## Style

- Typeface: Inter (diagrams and charts), Nunito (hero only, for the rounded clay look); both SIL OFL, bundled in
  `src/fonts/` with their licenses. Without them the scripts fall back to DejaVu Sans.
- Colors carry one meaning across every figure: blue `#2a78d6` physics and simulation, orange `#eb6834` learned world
  models, aqua `#1baf7a` real world and deployment, violet `#4a3aa7` data, training, and judging. Ordered categories
  (the three simulation generations) use a single-hue blue ramp. The four-hue set passes the colorblind-safety check
  (all-pairs CVD ΔE ≥ 9.2) of the dataviz validator; every colored mark also carries a text label, so color is never
  the only cue.
- Text is always ink (`#0b0b0b` / `#52514e` / `#898781`), never the series color. Light mode only.

## Regenerate

```bash
python3 -m venv .venv && .venv/bin/pip install matplotlib numpy
.venv/bin/python physical-ai-project/figures/src/make_figures.py            # everything, including the hero
.venv/bin/python physical-ai-project/figures/src/make_figures.py flywheel   # one figure
.venv/bin/python physical-ai-project/figures/src/make_hero.py               # hero only
```

`src/figkit.py` holds the shared canvas (pixel coordinates, y down), palette, text measuring and wrapping, and box/chip/arrow
helpers. Figure names: `stack`, `three-generations`, `newton-loop`, `newton-memory`, `flywheel`, `project-architecture`,
`cosmos3-modes`, `hero`.
